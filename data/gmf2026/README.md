# 그랜드 민트 페스티벌 2026 (gmf2026)

2026-10-17~18, 올림픽공원. 판정 모듈 `catalog` 형식 데이터와 대조 출처. Linear MIN-260.

| 파일 | 내용 |
| --- | --- |
| `catalog.json` | 판정 모듈 입력. 스테이지 3개, 공연 48개, 아티스트 48팀 |
| `timetable_source.csv` | 공식 타임테이블 원본 표기 그대로의 전사 (음악 공연 48행 + RADAR 12행, 종료 미기재는 빈칸) |
| `artists.csv` | 아티스트별 국적과 근거 URL |
| `sources.md` | 원본 게시물·이미지 URL·게시일·SHA-256. 이미지 파일은 저작물이라 레포에 넣지 않음 |

## 원본

민트페이퍼 공식 공지 2026-09-29 (https://www.mintpaper.co.kr/posts/4806). 확인 시점 2026-10-13, 홈페이지 기준 변경 공지 없음. 공식 인스타그램은 미확인 (10/16 확인 예정).

## 대조

원본 이미지의 공연 박스 테두리 위치를 픽셀로 재서 전사된 시각과 비교했다. 명시된 시작·종료 90개 지점이 모두 0.4분 이내로 일치.

3. **헤드라이너 표시**: 양일 모두 그날 가장 늦게 시작하는 공연이 CMS다. 10/17 이승윤, 10/18 십란에 `headliner: true`. 근거: 공식 타임테이블상 축제의 마지막 무대이며, 메인 마지막 공연(이소라·윤하)보다 늦게 끝난다.
4. **하이파이유니콘 국적 = UNKNOWN**: 한일 멤버 구성이고 한국·일본에서 함께 활동해 단일 국가를 정하지 않았다. 나머지 47팀은 KR.
5. **RADAR 제외**: 사인회·토크·공개방송·풍선아트쇼라 음악 공연이 아니다. 전사표에만 남겼다.
